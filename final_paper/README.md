## Compiling

### Overleaf
1. Create a new blank project.
2. Upload `main.tex`, `references.bib`, and the `figures/` folder (drag-and-drop the folder directly into the project root).
3. Set the main document to `main.tex`.
4. Overleaf's default toolchain (pdflatex + bibtex + pdflatex + pdflatex) compiles it without modification.

### Local
```bash
pdflatex main
bibtex  main
pdflatex main
pdflatex main
```
